## Changes

- Add compatibility with DeepSeek Harness 0.1.7-rc.2.

## Notes

As of 2026-09-24, npm tags: `latest`: 0.1.5-rc.3, `next`: 0.1.7-rc.2, `alpha`: 0.1.7-alpha.2.

To run DeepSeek Harness 0.1.7-rc.2, use:

```sh
npx @deepseek-ai/dsh@next web
```

To install or update the Claude Provider plugin to 0.5.3, use:

```sh
npx @deepseek-ai/dsh plugin --profile web add @mofeng2223/dsh-claude-provider@0.5.3
```
